## 💡 공부한 내용 본인의 언어로 정리하기

### 1. VSCode 개발 환경 구축 및 실습
개발 생산성을 높이기 위해 편집기 설정 및 프로젝트 구조 관리 방법을 익혔다.

- **VSCode 설치 및 기본 동작**:
  - 프로그램 설치 후 작업 디렉터리(폴더)를 열어 개발 환경 생성
  - 디렉터리 내에서 효율적으로 파일 및 하위 폴더를 생성하고 관리하는 방법 습득
- **확장팩(Extension) 활용**:
  - **Material Icon Theme**: 파일 및 폴더 종류에 따라 직관적인 아이콘을 표시해 주는 확장팩 설치
  - CSS, JS 등 별도로 분리된 폴더 구조를 한눈에 식별하기 용이하도록 관리 환경 구성

---

### 2. HTML 기본 구조 이해
웹 페이지의 기본 뼈대가 되는 HTML의 기본 태그 계층 구조를 학습했다.

- **`<html> ~ </html>`**: 전체 HTML 문서를 감싸는 최상위 태그
- **`<head> ~ </head>`**:
  - 브라우저 화면에 직접 표시되지는 않지만, 문서의 메타데이터(제목, 인코딩, 외부 CSS/JS 파일 연결 등)를 정의하는 영역
- **`<body> ~ </body>`**:
  - 실제 사용자 눈에 보이는 웹 페이지의 본문 콘텐츠(텍스트, 이미지, 버튼 등)가 위치하는 영역

---

### 3. 웹 프로젝트 디렉터리 관리 팁
- HTML, CSS, JavaScript 파일이 섞이지 않도록 기능별/역할별 폴더로 구별하여 관리
- `styles/`(CSS), `scripts/`(JS), `images/` 등 별도 폴더를 구성하여 프로젝트의 가독성과 유지보수성을 확보
