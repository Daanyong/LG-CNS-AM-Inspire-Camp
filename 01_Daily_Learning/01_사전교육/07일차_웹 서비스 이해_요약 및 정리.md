## 💡 공부한 내용 본인의 언어로 정리하기

### 1. HTML 문법 및 구문 작성 규칙 (`<body>` 구역)
- **가독성 규칙**: 개행(줄바꿈), 들여쓰기, 대소문자 구분을 철저히 신경 써서 가독성을 확보함
- **태그와 속성(Attribute) 구조**:
  - 기본 문법: `<tag attr="value">text</tag>`
  - 태그는 속성(Attribute)을 가지며, 속성은 값(Value)을 가짐
  - 태그 내부에 텍스트 외에도 또 다른 태그들을 중첩(Nesting)하여 구성할 수 있음
- **연산자 구분**: `=`은 할당 연산자이며, `==` 또는 `===`가 같음을 비교하는 연산자임
- **주석 문법**: `<!-- 주석 내용 -->`을 사용해 코드 설명을 남기거나 비활성화함

---

### 2. 실행 환경 구축 및 CSS 연동
- **Open with Live Server**:
  - 실시간으로 변경 사항을 확인하기 위해 Live Server 확장 프로그램 활용
  - 로컬 실행 시 기본 주소: `127.0.0.1` (Loopback IP / localhost)
- **CSS 구문 및 연동**:
  - 기본 문법: `선택자(selector) { key: value; key: value; }`
  - HTML 파일의 `<head> ~ </head>` 구역 내에서 `<link>` 태그를 활용해 외부 CSS 파일을 연동함

---

### 3. 상호작용 및 웹 요소 접근 (`<form>`, class, id)
- **`<form>` 태그**: 사용자 입력을 받아 서버로 전송하기 위한 데이터 수집 구역 구성
- **속성별 역할 구분**:
  - `class` 속성: 주로 **CSS 스타일링 접근** 시 활용 (다중 적용 가능)
  - `id` 속성: 주로 **JavaScript DOM 접근** 시 활용 (고유 식별자)
- **개발자 도구 (F12)**: 브라우저 실행 후 F12를 통해 요소 검사 및 디버깅 진행
