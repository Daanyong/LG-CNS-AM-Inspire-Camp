## 💡 공부한 내용 정리하기

### 1. 컴포넌트와 엘리먼트
리액트를 처음 접했을 때 제일 많이 들은 단어들인데, 쉽게 말해 **붕어빵 틀과 붕어빵** 같은 느낌이다.

- **컴포넌트**: 화면을 이루는 재사용 가능한 하나의 **부품(붕어빵 틀)**
  - UI 조각을 만들어 두고 필요할 때마다 가져다 쓸 수 있음
  - 자바스크립트 함수나 클래스 형태로 작성함
- **엘리먼트**: 컴포넌트를 통해 완성된 **가장 작은 단위의 화면 요소(완성된 붕어빵)**
  - 화면에 실제로 그려질 HTML 태그 형태의 결과물 (예: `<h1>Hello</h1>`)

---

### 2. Props와 Rendering
- **Props**: 컴포넌트에 전달하는 **데이터(붕어빵 속 재료 - 팥, 슈크림, 고구마 등)**
  - 같은 붕어빵 틀(컴포넌트)이라도 속재료(Props)로 **팥**을 넣으면 팥붕어빵이 되고, **슈크림**을 넣으면 슈크림붕어빵이 됨!
  - 부모가 전달해주는 읽기 전용(Read-only) 데이터라 자식 컴포넌트 내부에서 임의로 바꿀 수 없음
- **렌더링**: 작성한 리액트 코드를 브라우저 화면에 **그려내는 과정(붕어빵을 구워내는 과정)**
  - 데이터(Props나 State)가 변경되면 리액트가 알아서 화면을 다시 새로 그려줌(리렌더링)

## 🎯 오늘의 회고

### 1. 몰입도 및 소회
컴포넌트, 엘리먼트, 프롭스, 렌더링 등 생소한 단어가 많았다. "컴포넌트는 붕어빵 틀, Props는 팥/슈크림/고구마 같은 속재료"라는 설명이 좋았다. 하나의 컴포넌트를 만들어두고 Props만 바꿔서 재사용하는 리액트를 더 배우면 더 재밌을 것 같다.
