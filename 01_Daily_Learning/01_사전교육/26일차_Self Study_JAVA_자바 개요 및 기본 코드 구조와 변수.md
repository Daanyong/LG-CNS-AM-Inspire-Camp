## 💡 공부한 내용 정리하기

### 1. 자바 코드의 기본 구조 및 main 메서드
- **클래스 블록**: 자바의 모든 코드는 클래스 내부에 작성되어야 함
- **`public static void main(String[] args)`**: 자바 프로그램이 실행될 때 가장 먼저 찾아 들어가는 핵심 메서드
- **자바 파일 컴파일**: 작성한 소스 코드(`.java`)는 자바 컴파일러를 통해 바이트코드(`.class`)로 변환된 후 JVM 위에서 실행됨

---

### 2. 변수와 자료형
- **변수**: 데이터를 메모리에 저장하기 위해 할당하는 공간
- **주요 자료형 분류**:
  - **정수형**: `int`, `long`
  - **실수형**: `float`, `double`
  - **문자 및 문자열**: `char`, `String`
  - **논리형**: `boolean`

---

### 3. 식별자 이름 짓는 규칙
- **클래스 이름**: 대문자로 시작하며 단어가 연결될 때 대문자로 표기
  - 예: `HelloWorld`, `TestController`
- **메서드 및 변수 이름**: 소문자로 시작하며 단어가 연결될 때 대문자로 표기
  - 예: `userName`, `calculateTotal()`

---

### 4. 올바른 주석 작성법
- **라인 주석 (`//`)**: 한 줄 설명을 작성할 때 사용
- **블록 주석 (`/* */`)**: 여러 줄을 한 번에 주석 처리할 때 사용
- **주석 작성 팁**: 단순히 코드를 직역하는 주석보다는 작성된 코드의 이유나 핵심 의도를 명확하게 기록하는 것이 중요함

## 💻 자바 기초 실습 코드 예시

```java
// 클래스 선언
public class HelloWorld {

    /*
      여러 줄 주석:
      자바 프로그램의 시작점인 main 메서드 정의
     */
    public static void main(String[] args) {
        
        // 변수 선언 및 자료형 대입
        int studentAge = 24;
        String studentName = "dykang";
        boolean isEnrolled = true;

        // 콘솔 화면에 문자열 및 변수값 출력
        System.out.println("Hello, World!");
        System.out.println("학생 이름: " + studentName);
        System.out.println("학생 나이: " + studentAge);
        System.out.println("수강 여부: " + isEnrolled);
    }
}
```
