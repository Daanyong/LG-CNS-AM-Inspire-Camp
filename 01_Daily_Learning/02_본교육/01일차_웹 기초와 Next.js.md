## 오늘 배운 것 – 나만의 언어로 설명
- 시맨틱 태그는 검색엔진과 개발자 모두에게 웹 UI의 의미와 구조를 명확히 전달하는 도구이다.
- 단순히 구역을 나누기 위해 `div`를 남발하기보다 `header`, `nav`, `section`, `article`, `aside`, `footer` 등을 구분해 써야 한다.
- 특히 `footer` 내에 `address` 태그를 활용하면 검색엔진이 주소 정보를 정확히 파악하여 검색 결과 상단에 빠르게 노출하는 데 유리하다와 같은 팁?들이 좋았다.
- 개발자 도구(F12)를 통해 실제 웹페이지의 DOM 구조와 요소가 어떻게 렌더링되고 있는지 직접 검수하는 습관이 중요한 것 같다.
