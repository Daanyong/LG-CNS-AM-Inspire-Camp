## 💡 오늘의 학습 및 주요 구현 내용

### 1. 레시피 등록 페이지 유효성 검증 및 필수화
* 이슈: 레시피 작성 시 누락되면 안 되는 필수 항목(조리 시간, 인분 수, 난이도, 식재료, 종류, 카테고리, 맛 등)이 비어있어도 등록이 진행되던 문제 발생.

* 해결: handleSubmitRecipe 함수 내부에 필수 입력값 검증 로직을 추가하여, 누락된 항목이 있을 경우 사용자에게 alert 경고창을 띄우고 등록을 안전하게 차단하도록 구현.

### 2. 해시태그 키워드 입력 UX 개선
* 이슈: 사용자가 키워드를 직접 # 기호와 함께 입력해야 하는 번거로움이 있었음.

* 해결: + 추가 버튼을 누르거나 인풋이 활성화될 때 기본적으로 # 기호가 미리 입력되어 대기하도록 수정하고, 입력 완료 시 엔터 키를 통해 순수 키워드만 깔끔하게 추출되도록 개선.

### 3. 모바일 뷰포트 기준 하단 고정(Fixed) 버튼 스타일링
* 이슈: '레시피 저장하기' 버튼이 스크롤 맨 아래에 있어 접근성이 떨어짐.

* 해결:

  버튼을 감싸는 SubmitBox에 position: fixed와 bottom: 0을 적용하여 화면 하단에 항상 고정되도록 변경.

  모바일 화면 폭(430px)과 컨테이너 최대 너비를 일치시키고 margin: 0 auto로 가운데 정렬 처리.

  '피드에 공개하기' 토글과 저장 버튼 사이의 불필요한 여백을 최적화하여 시각적으로 안정감 있는 레이아웃 완성.

### 4. 식재료 검색 모달 배경 스크롤 방지 (Body Scroll Lock)
* 이슈: 식재료 검색 모달창을 띄운 상태에서도 뒤에 있는 레시피 작성 페이지의 스크롤이 함께 움직이는 불편함이 발생.

* 해결: 모달의 오픈 상태(isModalOpen)를 감지하는 useEffect를 추가하여, 모달이 열릴 때 document.body.style.overflow = 'hidden'으로 배경 스크롤을 차단하고 닫힐 때 다시 복구되도록 처리.
