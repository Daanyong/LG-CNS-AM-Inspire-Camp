## 💡 공부한 내용 본인의 언어로 정리하기

### 1. 프론트엔드 기초 기술 스택 (HTML, CSS, JS)
웹 브라우저를 통해 사용자에게 보여지는 화면을 기획하고 구현하는 영역이다.

- **HTML (HyperText Markup Language)**
  - 웹 페이지의 **뼈대(구조)** 를 형성함
  - 시맨틱 태그(`<header>`, `<article>`, `<footer>` 등)를 활용해 의미 있는 구조 전달
  - 검색 엔진 최적화(SEO) 및 웹 접근성(Accessibility) 확보에 필수적
- **CSS (Cascading Style Sheets)**
  - 웹 페이지의 **UI 스타일링** 담당
  - **반응형 디자인**: 미디어 쿼리(`@media screen and (max-width: 768px)`)를 사용해 PC 및 모바일 해상도에 맞춰 최적화
  - **최신 기법**: Flexbox, Grid Layout, CSS 변수(`--primary-color`), CSS-in-JS(`styled-components`, `emotion`)
- **JavaScript**
  - 웹 페이지의 **동적 기능**을 구현
  - 브라우저 내 이벤트 핸들링, DOM 조작, 서버 통신(`ajax`, `fetch`, `axios`)
  - Modern ES6+ 문법 활용 (`let/const`, 화살표 함수, `async/await` 등)

---

### 2. SPA (Single Page Application) 아키텍처
한 번 로드된 단일 HTML, CSS, JS 파일을 기반으로 동작하는 웹 애플리케이션 구조이다.

- **동작 방식**: 페이지 이동 시 전체를 다시 불러오지 않고, 필요한 데이터만 서버에서 받아와 동적으로 화면을 갱신함
- **장점**: 빠른 화면 전환, 앱과 같은 뛰어난 UX 제공, 서버 부하 감소
- **단점**: 초기 로딩 속도가 상대적으로 느림, 전체 HTML을 먼저 읽는 구조가 아니므로 SEO(검색 엔진 최적화)에 불리함
- **보완책**: SSR(Server-Side Rendering) 기술을 적용해 단점 보완

---

### 3. SPA 프레임워크 및 라이브러리 비교 (React vs Vue.js)

#### 1) React (라이브러리)
- Meta(Facebook) 개발, UI 구현에 특화
- **컴포넌트 기반 개발**: 재사용성과 유지보수성이 뛰어남
- **Virtual DOM**: 실제 DOM 조작을 최소화하여 성능 최적화
- **보완 생태계**:
  - 상태 관리: Redux, Recoil, Zustand
  - 라우팅: React Router
  - 빌드/SSR 도구: CRA, Vite, Next.js (SSR 지원)

#### 2) Vue.js (프레임워크)
- 가볍고 진입 장벽이 낮아 빠르게 습득 가능
- **템플릿 기반 코딩**: HTML + JS + CSS 구조를 직관적으로 통합 관리
- **반응성(Reactivity) 시스템**: 데이터 변경 시 UI가 자동으로 업데이트됨
- **보완 생태계**:
  - 라우팅: Vue Router
  - 상태 관리: Pinia, Vuex
  - SSR 도구: Nuxt.js (SSR/SSG 지원)
