## 💡 공부한 내용 본인의 언어로 정리하기

### 1. 메서드의 개념 및 문법 구조
메서드란 객체가 가지고 있는 기능 및 **데이터를 다루는 행위** 를 정의한 코드 블록이다.

- **클래스의 핵심 구성요소**: `클래스 = 변수(상태/속성) + 메서드(행위/기능)`
- **기본 구문 형식**:
  ```java
  [접근지정자] [반환타입] [메서드이름]([매개변수]) {
      // 실행할 코드 블록
  }
  ```
  - **매개변수**: 메서드 호출 시 외부로부터 전달받는 입력값 (있을 수도 있고, 없을 수도 있음)
  - **반환타입**: 메서드 실행 후 결과로 반환할 데이터의 타입 (반환값이 없을 경우 `void` 사용)

---

### 2. 반환타입과 매개변수 유무에 따른 메서드 4가지 유형
메서드는 매개변수와 반환타입의 존재 여부에 따라 4가지 형태로 분류된다.

1. **매개변수 O, 반환값 O**: 입력값을 받아 처리한 후 결과값을 반환함
   - 예: `public int add(int a, int b) { return a + b; }`
2. **매개변수 O, 반환값 X (`void`)**: 입력값을 받아서 내부 로직만 수행하고 반환하지 않음
   - 예: `public void printName(String name) { System.out.println(name); }`
3. **매개변수 X, 반환값 O**: 입력값 없이 내부 데이터를 처리하여 결과값을 반환함
   - 예: `public String getGreeting() { return "Hello"; }`
4. **매개변수 X, 반환값 X (`void`)**: 입력값도 없고 결과 반환도 없이 단순 동작만 수행함
   - 예: `public void sayHello() { System.out.println("Hello World"); }`

## 💻 Java 실습 코드 분석

```java
public class MethodApp {

    // 자바 프로그램의 시작점이 되는 main 메서드
    // 반환타입: void (반환값 없음)
    // 매개변수: String[] args (문자열 배열 형태의 매개변수)
    public static void main(String[] args) {
        
        // main 메서드 내부에 선언된 지역변수
        // 해당 메서드 블록 { } 내부에서만 존재하고 사용됨
        String msg = "이 곳은 프로그램의 시작점 입니다.";
        
    }
}
```
