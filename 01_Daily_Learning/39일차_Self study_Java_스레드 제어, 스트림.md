## 💡 공부한 내용 정리하기

### 1. 스레드와 동기화 처리
- 스레드 생성: 하나의 프로세스 안에서 여러 작업을 동시에 실행할 수 있는 단위로, `Thread` 클래스를 상속받거나 `Runnable` 인터페이스를 구현해 사용할 수 있음
- 순서 보장 불가: 스레드를 실행시키면 각 스레드는 순서에 상관없이 병렬로 작동함
- `join` 메서드: 스레드의 작업이 모두 완료될 때까지 메인 흐름이 기다리도록 제어하여 순서를 동기화함
